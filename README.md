# 🧩 LexiHunt: Visual English Puzzle App

## 📝 Project Overview & Problems Solved

An interactive mobile application designed for Spanish speakers to learn English naturally and intuitively through **Comprehensible Input** principles.

Say goodbye to dry translations and boring memorization lists: users master new vocabulary by matching puzzle words directly with real images, forcing the brain to think directly in English. Furthermore, it incorporates gamification (coins, avatars, and a pet shop) to maximize user retention and daily engagement while solving thematic mobile word searches.

## 🛠️ Technologies Used

- **Mobile Frontend:** React Native (Expo) / JavaScript
- **Backend Automation & Logic:** Python (FastAPI)
- **Database:** SQL Server (for relational structured data like categories, users, and items)
- **Local Storage:** AsyncStorage / SQLite (for offline progress)
- **Version Control:** Git & GitHub
